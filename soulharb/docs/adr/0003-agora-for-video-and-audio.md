# ADR 0003: Agora for video and audio

- Status: Accepted
- Date: 2026-11-20

## Context

Source documents named several video vendors (Daily, Twilio, Whereby, Agora).

## Decision

Use Agora for interviews and, later, listening sessions. The API issues short-lived tokens.

## Consequences

One vendor to integrate and monitor. Recording is not part of Phase 1 (see ADR 0010).
